这是当前维护者 Mac 实际安装的 C31 应用包的完整发布副本，保留原有 macOS 界面、额度、产物与图片反馈、中文设置和磁盘管理等定制功能。**C31 是社区构建编号；包内官方版本标记仍为 0.1.5，不是新的官方 T3 版本。** C31 继承 C30 已合入的上游更新，并加入下述修复。

## 本次变化

- 修复新会话创建前的临时 404 被当作会话已删除，导致助手正文与运行详情一直不更新的问题。共享订阅在服务端确认会话存在后恢复，无需刷新页面。
- 修复空白草稿没有 runtime 时被错误显示为断连的问题；真实环境失联仍按断连处理。
- 当前会话侧栏显示任务完成数、阶段和进度条；完整步骤保留在运行面板。
- 补齐审批、工作状态、运行详情与相关动态文案的中文显示。

## 下载与安装

下载 `Xiaoxin-T3-Code-C31-macOS-arm64.zip`，解压后得到 `T3 Code (Alpha).app`。仅适用于 Apple Silicon Mac；不包含 Intel Mac 或 Windows 程序。

已经运行本机这一版的维护者无需重复安装。其他使用者替换前应结束任务并完整退出 T3，保留旧应用供回退，然后替换应用。不要删除、重置或覆盖 T3 的用户数据目录；同一份数据只运行一个应用实例。各模型仍需要使用者自己的 CLI、登录或供应商配置。

程序保留现有临时签名，**未经过 Apple 公证**。macOS 如阻止打开，请按系统提供的“隐私与安全性”提示处理；本发布不修改系统安全设置。

## 验证与限制

- 发布副本的 159 个文件、14 个符号链接及文件权限与在用安装版逐项相同，ASAR 未重新编译或改写。签名、ZIP CRC 与逐文件 SHA-256 核对通过。
- 同一 ASAR 此前已在真实 Mac 桌面验证：新会话第一轮、同会话第二轮无需刷新显示回复；先前失败会话可正常读回。该结论不扩展为所有供应商均已验收，也不宣称解决了独立的 Antigravity 启动故障。
- 本次另外从发布应用副本启动空白隔离环境，核对服务、SQLite 和网页入口加载；未调用模型，未使用生产聊天数据。
- 本次源码检查：233 个相关测试、20 项 React Compiler 检查、7 个包类型检查通过；格式检查仍有 2 个文件，lint 有 3 项，knip exports 有 3 个回放导出遗留项，**完整检查尚未全绿**。本次保留已安装 C31 的源码与行为，没有为通过检查引入额外界面改动。
- 未验证所有供应商、所有尺寸或长期空闲 CPU 表现。
- 包中不包含维护者的账号、聊天、项目内容、密钥、私有设置或实测截图。重新安装不代替备份；本机正在使用的应用没有被替换。

校验文件与不含个人数据的构建、隔离启动记录随 Release 提供。默认主线为 `main`，C31 归档分支为 `community/xiaoxin-c31`；Windows 版本继续保留在独立分支与发行页。

发行状态更新：C31 现为仓库的正式推荐版与 Latest，取代默认旧版下载。此次只统一发布入口并更新打包说明，应用文件没有变化；上面的验证范围和遗留项仍然适用。
