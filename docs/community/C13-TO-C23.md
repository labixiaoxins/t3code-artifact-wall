# C13 → C23：这次升级到底变了什么

[English](C13-TO-C23.en.md) · [首页](../../README.md) · [下载 C23](https://github.com/labixiaoxins/t3code-artifact-wall/releases/tag/xiaoxin-c23-20261028)

上一次公开发行是 **C13，官方 0.1.1 基线**；这次是 **C23，完整官方 0.1.3 基线**。中间积累了内核、搜索、额度保护、任务可观察性、存储操作和界面交互的多轮改动。它并不只是把输入框改小，或把侧栏换成图标。

![C13 到 C23 升级概览](../../assets/community/c23/08-c13-to-c23.png)

## 先看完整对照

| 方面 | 上次公开的 C13 | 本次 C23 | 对日常工作的意义 |
| --- | --- | --- | --- |
| 官方基础 | 官方 0.1.1 + 当时适用的少量回补 | 完整官方 0.1.3 + 保留的适用回补 | 模型会话、文档、搜索、恢复与状态处理一起更新 |
| 历史检索 | 已有中文/拼音项目导航与会话搜索 | 增加本机 Spotlight 检索服务、可重建全文索引和命中定位 | 不只记标题，也能通过历史内容找回上下文 |
| Claude 额度 | 已有剩余额度常显 | 增加可选的订阅额度保护和按账号的启动协调 | 开启后避免在额度不明或接近收尾线时继续放入新任务 |
| 运行详情 | 已有正在进行与跨模型任务概览 | 增加运行详情：实际回报模型、请求模型、推理强度、账号别名、额度时间与子任务状态 | 看清是谁实际在跑，区分期望配置与真实回报 |
| 磁盘治理 | 未包含本轮 StorageManagement 服务 | 下钻检查、计划、外盘归档、内容/元数据校验、受控释放、记录与恢复 | 可以按具体范围处理，且保留恢复路径 |
| 增长防护 | 没有本轮新增的容量预检入口 | 部分构建、打包与更新入口接入预算门禁；完整基线纳入数据库维护改进 | 减少已接入入口的大写入风险，不能拦截全系统任意写盘 |
| 会审与模型偏好 | 未包含本轮会审请求入口 | 明确会审请求，模型偏好收进模型菜单 | 不再把单模型书签包装成已运行的三方流程 |
| 侧栏和模型菜单 | 项目优先侧栏；提供方文字标签；较多重复来源信息 | 提供方图标化、标题减重、模型名保持单行、同名时保留账号短标签 | 标题能多显示一些，选择列表更紧凑 |
| 输入区 | 旧版输入区与控制排布 | 默认三行半、自动增高/滚动、轻量一致底栏 | 保留原模型 logo、Gauge 和权限含义，宽度不变 |
| 原有制作工作台 | 产物、视频、续聊、拼音搜索、额度常显 | 继续保留，并接到新的官方详情/用量入口 | 升级时保留已熟悉的项目工作方式 |

## 1. 内核是跨了两个正式基线

C13 的基础提交是 `fe27e8e3dc12dcbb108e9a28fd9b8cb65f34ae92`（0.1.1）；C23 的官方基础是 `d2c440312e5f39d59827ed466838a623516454d6`（0.1.3）。C20 阶段已经完整合并，C23 延续该基础。

这包含大量上游实现与结构调整，不能简写成“修了几个 bug”。几个与工作直接相关的例子是：

- PDF 跨行短语搜索等文档查看改进。
- 搜索/刷新遇到不可达环境时的处理修复。
- 工作区被删除后的后续消息恢复处理。
- 被后续状态替代的过程快照压缩、后台压缩状态显示与历史发现的写入协调。
- MCP 工具 schema 整理，以及适用的 Claude 工具缓存/会话、Codex 进程退出恢复等修补。

这些是纳入的实现，不能由此推定每个模型、每种系统都已经实测，也不能换算成固定的额度或性能收益。

## 2. 搜索从“找到任务”继续走向“找到那段内容”

C13 已经有中文、拼音全拼与首字母匹配，不能把这些重新算作新功能。之后增加的是本机 Spotlight 检索服务及其索引与结果定位衔接。

检索 worker 读取本地会话数据，用单独可重建缓存保存索引，不需要把聊天发给模型才能搜。返回的命中信息接入命令面板与会话定位。这里的 Spotlight 是**应用内服务名称**，不意味着接管 macOS 全盘 Spotlight。

## 3. 额度保护比“把百分比显示出来”多了一层

C13 的额度常显负责可见；新的 Claude 订阅保护在对应通道配置开启后，参与新消息、准备任务及排队任务的启动判断。

实现区分正常、提醒、收尾与未知状态，并协调同账号的任务启动。额度数据过期或不可读时不会当成可无限继续。相关提示和排队不是强杀正在运行的进程，也不保证平台额度永远准确；这是可选保护，不代表每个安装都已开启。

## 4. 看清“实际运行”与“准备运行”

新的运行详情可以分别查看实际回报模型与请求模型、推理选项、账号别名、额度检查时间及子任务状态。没有回报就显示未回报，额度不可读或过期有相应状态，不凭请求配置伪造实际使用模型。

子任务按需展开，先显示一部分再加载更多，避免把所有运行信息长期堆进主输入区。它补充 C13 的任务概览，而不是把旧概览重新命名成新功能。

## 5. 存储从排查走到可以执行与恢复

本轮新增的存储管理服务将检查、范围计划、归档、校验、符合条件时的释放及恢复记录连在一起。索引和小回执不再冒充需要淘汰的完整备份；未知恢复引用、独有内容或运行状态仍受保护。

这是产品能力。维护者之前手动清理飞书缓存、外迁个人历史或得到的个人磁盘余量，**没有打包成下载后自动执行的功能，也不作为本版释放空间的承诺**。用户仍需要检查自己电脑的实际对象与恢复条件。

## 6. 最近的界面调整是这批更新的最后一层

项目侧栏、产物、视频、续聊与额度常显本来已经存在，C23 继续保留。新增的重点是用图标给标题让位、去掉模型列表重复来源、降低文字厚重感，以及最终确定的三行半与 A1 轻量底栏。

手动高度拖动曾在内部试验，最终已移除；本次下载的状态以 C23 为准，不要求用户经历每个中间版本。

## 内部阶段与公开发行不要混淆

- **C13**：上一次公开的项目工作台与界面模板。
- **C16 阶段**：检索、额度保护、运行详情等能力的整合。
- **C17～C19 阶段**：存储闭环、适用后端修补、模型菜单和侧栏改进。
- **C20**：完整升级到官方 0.1.3。
- **C21～C23**：根据实际反馈收敛输入高度与底部控件。

这是内部迭代脉络，**不等于中间有十个对外独立发布的大版本**。C23 可作为从 C13 升级的目标，但需要按 [备份与回退说明](README.md) 处理，不能把程序替换等同于数据库兼容保证。

## 核对依据

对照固定的 C13 提交 `b7dee7a38546ac341a73c7f528bec6f415f22c0a` 与 C23 实现 `6d3627c85508ab2bb45c7f1bf04b07f170d00e2b`。例如下列模块在 C13 中不存在，在 C23 中已集成：`SpotlightSearch`、`ClaudeUsageProtection`、`RunInspector`、`StorageManagement`。原 C13 FEATURES 中已写明的产物、续聊、拼音导航与额度常显作为保留项列示。
