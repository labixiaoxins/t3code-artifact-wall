## 下载和安装

1. 从 [C28 Release](https://github.com/labixiaoxins/xiaoxin-t3code/releases/tag/xiaoxin-c28-20261030) 下载 `Xiaoxin-T3-Code-C28-macOS-arm64.zip` 和 `SHA256SUMS.txt`。这是 Apple 芯片 Mac 包；最低 macOS 要求以同页 release-manifest.json 为准。
2. 在下载目录运行 `shasum -a 256 -c SHA256SUMS.txt`，按提示核对已下载文件；若只下载了部分附件，可只校验对应行。解压后将 App 放进“应用程序”。不要直接在 ZIP、外盘归档或下载暂存中长期运行。
3. 此包为未经 Apple 公证的社区临时签名应用。首次被系统阻止时，核对本仓库、校验值及应用来源，再在“系统设置 → 隐私与安全性”使用系统允许的打开方式。不要关闭全局安全防护。
4. 登录自己的模型提供方账号。本包不附带维护者账号、API 地址、订阅、私人技能或聊天资料。

## 已有 T3 升级

本版沿用 T3 应用身份与数据位置，不是自动隔离的第二套安装。**不要同时运行官方版与社区版。**

1. 等所有任务完成，从菜单正常退出，确认旧应用与后台服务停止。
2. 保存同一时点的完整应用、T3 home（默认 `~/.t3`）及桌面持久状态（本包默认 `~/Library/Application Support/t3code-v2`）。自定义 home/外部引用应按自己的配置一并备份。凭据和资料备份只留在自己的设备。
3. 替换应用并启动，核对原项目、会话、登录、模型通道、快捷键与设置。新版本可能执行上游数据库迁移或状态维护；应用回滚和数据库回滚不是一回事。

## 恢复与回退

先保全升级后当前应用和一致性数据快照；在**全新的目录**恢复旧的配对应用/配置/数据库，隔离检查后再决定是否切回。不要直接用旧库覆盖唯一现存资料，不要让旧程序盲写新库。

如果必须恢复旧数据库，备份之后的新聊天和变更不会自动合并。先识别差异并导出新增内容，明确接受损失后才执行破坏性覆盖。本发行 ZIP 不含强制退出、自动清库、直接覆盖或迁移个人数据的安装脚本。

## 空间管理

在“用量 → 磁盘空间”检查所选环境，先看测量时间，再下钻、选目标卷、预览范围。只归档保留原件；归档并释放需要符合审查条件。未知运行引用、未验收回滚链或独有文件不会仅按时间自动退役。外盘断开时查询本机索引；恢复应写入新目录。

## 从源码运行

源码分支 `community/xiaoxin-c28`，发布 tag `xiaoxin-c28-20261030`。安装根 `package.json` 要求的 Node.js 与 Vite+，再执行 `vp i` 和 `vp run dev --no-seed`。开发 home 与正式资料分开；不要把正式 `~/.t3/userdata` 当作测试服务器的数据目录。

官方基线为 0.1.5；构建阶段使用 `scripts/update-release-package-versions.ts 0.1.5` 对齐发行包版本。仓库 package.json 中的基础版本字段不应单独被当成已安装发行身份。
