# Xiaoxin T3 Code C29：设置汉化与工程修复

[English](RELEASE.en.md) · 2026-10-30

C29 延续基于官方 0.1.5 的 Xiaoxin 定制版，补齐设置页的中文体验，并修复 C28 公开记录中的工程检查问题。本轮没有合并新的官方主线、nightly 或待审 PR。

## 设置页的变化

- 设置分类、导航、面包屑、搜索结果和说明接入现有中英文目录；可以用中文查找相关设置。
- 补齐动态说明，以及加载、归档空列表、失败、未登录、检查更新和离线 webhook 等条件分支的文案。
- 保留产品名称、命令、网址、用户填写的内容及未知外部诊断原文，避免翻译改变其含义。
- 通过语言菜单保存语言后重新加载，可在简体中文与英文之间切换；不需要清空聊天或设置。
- 沿用现有国际化实现，没有引入新的翻译框架。

## 功能与工程修复

- 修复 ContextHandoffNotice、StorageManagementPanel 等本次涉及组件的 React Compiler 阻塞，并完善必要的生命周期处理。
- 修复 AgentContextBudget 预算核算、测试引用、未使用导出和动态 worker 的 knip 入口声明。
- 补齐锁文件所要求的构建依赖，恢复外围包类型检查；没有通过删除受影响模块来绕过检查。
- Claude 明确拒绝本地压缩时显示失败，避免把未完成的压缩报告为成功；中断仍保留中断状态。
- 修复只读配置历史显示的保留期限：即使浏览器存储写入失败，过期记录也不继续展示。
- 重置富文本输入框时只重置对应设置，不再连带改变图片修改意见开关；去除重复认证状态链接。
- 安装配置保护仅忽略模型目录根级 `fetchedAtMs` 刷新时间，其他配置和登录内容仍严格核验，避免正常目录刷新触发误回滚。

## 升级与恢复

升级前保留现有配置、聊天数据和可用应用备份，等正在执行的任务结束后再替换程序。维护者的本机安装流程保留了 C28 回滚应用与数据冷备份，并核验已有数据和登录信息不变。该本机安装流程的验证，不表示每个下载或安装方式都经过同等验证。

需要恢复时先恢复程序版本，不要用旧数据库覆盖升级后新增的聊天。带有任务活动或用户输入干扰的 CPU 采样窗口不能当作性能失败。
