# C13 改版特点：从会话列表到项目工作台

C13 面向同时管理多个项目、切换多个模型、交付图文和视频的人。目标是减少找项目、找文件、看进度时的来回切换，并让工作台的视觉层次更清楚。它不改变模型本身的智力、订阅规则或权限边界。

**比较口径：** 下文的“官方基线”特指本分支采用的 [v0.1.1](https://github.com/pingdotgg/t3code/tree/fe27e8e3dc12dcbb108e9a28fd9b8cb65f34ae92)。2026-10-26 核查时官方最新稳定版为 [v0.1.2](https://github.com/pingdotgg/t3code/releases/tag/v0.1.2)，其全部变更尚未移植。上游仍持续迭代，不能由本表推断官方最新版本永久缺少某项能力。

## 一眼看懂差别

| 工作情境 | 官方基线与既有能力 | 本分支增加或重新组织的部分 | 实际价值 |
|---|---|---|---|
| 同一项目用多个模型 | 上游提供多模型、项目与会话 | 中文工作区分类合并展示，默认按项目；可切回按模型 | 减少在模型分组之间来回找同一类工作 |
| 中文项目很多 | 上游有命令面板与搜索 | 项目结果优先、全拼/首字母匹配、会话与消息内容分组 | 记得项目名就能快速进入，不必先想起会话标题 |
| 图文与视频交付 | 上游已有会话与文件工具 | 产物墙延续，视频独立筛选、时长、内联播放 | 交付内容可见，减少往返 Finder 查找 |
| 右侧信息太多 | 上游有详情与相关面板 | 产物 / 续聊 / 项目三标签检查器 | 需要时展开，聊天区更完整 |
| 多账号轮流工作 | 上游有通道与用量能力 | 可配置的剩余额度常显与窗口选择 | 选择通道时少进几次设置页 |
| 经常续聊 | 上游保存线程与历史 | 关联前序会话的只读回看、草稿恢复提示 | 更方便查旧决策、衔接工作；不自动消耗模型额度 |
| 日常桌面使用 | 上游提供桌面壳及布局 | 浅深色材质层、字标对齐、紧凑标签、中文标题 | 视觉层次更统一，长时间使用时少些干扰 |

其中产物墙、额度常显、续聊回看与任务概览是之前 C11 已发布的定制，C13 继续保留；项目搜索、项目优先侧栏、视频、检查器和外观细节是这次的主要变化。

## 1. 左侧导航围绕项目组织

以前按模型展开时，同一类工作会分散在 Codex、Claude 等不同分组下。C13 默认将同一工作区分类合并，模型信息放回会话行末尾，以轻量文字标识。侧栏保留“正在进行”“待我处理”“历史与归档”和项目工具。

常用分类可以右键置顶；其余按活动时间放入“最近”，超过 14 天无活动的分类收进“更多项目”。当前会话仍会被展开定位。分组方式可以切回按模型，偏好保存在本机。

这里的顶层项目视图沿用本分支的**工作区分类**，例如“项目管理”“自媒体”“AI 工作台”；它不是新建一套数据库项目结构。命令面板则可以匹配分类内的具体项目。置顶也作用于侧栏分组，不等同于给任意单条会话置顶。

依据：[侧栏逻辑](../../apps/web/src/sidebarProjectFirst.ts)、[侧栏实现](../../apps/web/src/components/LegacySidebar.tsx)。

## 2. ⌘K 先找到项目，再进入会话

输入查询词后，命令面板先列出匹配项目，再列会话，最后单独列“消息内容匹配”。中文名可以用全拼或首字母匹配：虚构项目“批量设计工具”可输入 `piliang` 或 `plsj`。项目名称、路径末级名称都能参与匹配。

选中具体项目后，进入它最近的会话；还没有会话时打开新建草稿，并让侧栏定位到所属分组。本版还移植了上游 [#24032](https://github.com/pingdotgg/t3code/pull/24032) 中适用的搜索排序和隐藏子任务结果改进，这部分归功于上游。

拼音组件按需加载，不为首页预先加载整个词库。已覆盖加载中输入后结果刷新的检查，但未发布“零延迟”或大规模项目数性能结论。

依据：[中文项目匹配](../../apps/web/src/components/CommandPalette.projectSearch.ts)、[命令面板](../../apps/web/src/components/CommandPalette.tsx)。

## 3. 让成果从聊天里浮出来

本分支的产物面板让图片、页面、文档和视频有独立入口，可以按本会话或本项目查看。C13 将 MP4、MOV、M4V、WebM 作为视频收录，显示缩略图与时长，点击后内联播放，保留在 Finder 中显示的入口。播放器不自动播放，元数据按需加载。

图片和视频用卡片，文档采用紧凑列表，减少狭窄检查器里的无效占位。对于设计、动效和自媒体任务，用户可以直接检查“交付了什么”，而不是只看到模型说“完成了”。

**收录不等于验收。** 文件存在、播放器可解码、检查命令通过、人工视觉/听觉验收是不同层次。产物检查信息继续绑定具体文件版本；本版不会把“检查通过”转换成用户接受。容器扩展名支持也不代表所有视频编码都能播放。

依据：[视频收录](../../apps/server/src/artifacts/collection.ts)、[产物界面](../../apps/web/src/components/chat/ArtifactWall.tsx)、[产物契约](../../packages/contracts/src/artifactWall.ts)。

## 4. 右侧变成按需打开的检查器

“产物 / 续聊 / 项目”分成三个标签，一次只展示当前要看的内容。⌘⌥I 开关右栏，重新打开时记住上次选择；新建草稿只显示当时可用的标签。前序会话仍是只读回看，不会因为切标签而自动重新发送给模型。

相比把几块信息始终堆在一起，检查器把主会话留在视觉中心，也让产物、项目细节与历史各有明确入口。快捷键通过应用既有的默认迁移追加，用户已有绑定继续保留。

依据：[检查器标签](../../apps/web/src/inspectorTabs.ts)、[详情面板](../../apps/web/src/components/chat/ThreadDetailsPanel.tsx)。

## 5. 外观有统一的层次，但保留熟悉的操作

C12 引入的材质层在 C13 继续保留：浅色使用柔和渐变和半透明侧栏，深色使用石墨灰；侧栏与检查器形成内缩圆角，工具入口使用胶囊容器。它是 CSS 玻璃质感，**不是 Apple 原生 Liquid Glass 的技术承诺**。系统偏好减少透明度或增加对比度时有相应降级。

C13 修正浮动侧栏内缩导致的字标偏移，让字标与侧栏开关保持同一中线；模型标签采用 10px 的低对比度文字。新会话标题补齐中文，路径行显示最后一级文件夹，完整路径仍可悬停查看。用量页已有自己的限额视图，因此隐藏重复的顶部额度胶囊，其他页面继续显示。

完整浅深色[展示图与离线模板](../../assets/community/c13/showcase.html)使用虚构数据，只用于说明界面方向和信息布局。它们是可编辑的 SVG/HTML，不是生产截图，也不是独立运行的 T3 客户端。

依据：[材质样式](../../apps/web/src/liquidGlass.css)、[侧栏字标](../../apps/web/src/components/sidebar/SidebarChrome.tsx)、[页面头部](../../apps/web/src/components/WorkspacePageHeader.tsx)。

## 6. 额度可见，未知状态也说清楚

C11 的额度常显继续保留：从顶部入口选择账号、额度窗口和顺序，默认 3 项、最多 4 项，复用已有用量快照。用量页的 token/费用统计和订阅限额是不同指标；本分支没有把它们混成一个“余额”。

缺数据、接口不支持、过期和读取失败按状态处理，不自动补为 0% 或 100%。Antigravity 可能给出 Claude/GPT 共享周窗口，不能称作 Gemini 独享余额；APIyi、WorkBuddy、豆包没有通用余额覆盖。界面更方便不等于获得额外订阅额度。

## 7. 稳定性修补与已有能力一起保留

C13 r5 合入外部应用提示循环修复：后台/定时网页导航不反复弹出“打开外部应用”，当前标签页中用户取消过的站点/协议提示有记忆。该修复与界面版本同时发布，避免升级后丢失。

此前的时间线/右面板切换修复、草稿恢复、跨模型任务概览和成果检查继续保留。不是所有错误都已修完：lint 有已记录的既有错误，本次没有把它写成全仓通过。

## 选择这个分支的代价

这个版本更适合认可中文分类和三栏布局的人。若更需要官方新版本的全部修复、跨平台预编译包、Apple 公证或官方支持，应优先选官方版本。C13 当前只提供 macOS arm64 包，仍基于 v0.1.1；没有升级模型能力、免费额度或平台政策保证。

本机安装与针对性测试有记录，但真机全屏、原生右键置顶、接收者账号登录、所有模型调用、远程与移动端仍不能从展示模板推定通过。独立刘海应用不在本包，未在图中伪装成内置功能。详见[安装、回滚和验证范围](README.md)。
